# Задача «Грибочки»: определяем, ядовитый гриб или нет

Вам предстоит решить задачу бинарной классификации: по свойствам гриба необходимо определить, является ли он ядовитым.

Данные основаны на классическом наборе о морфологических характеристиках грибов. Все признаки представлены в виде категориальных значений, описывающих внешний вид и свойства найденного гриба.

## Формулировка задачи

Требуется предсказать переменную:

**`is_poisonous`**  
- 1 — гриб ядовитый  
- 0 — гриб съедобный  

По остальным признакам необходимо обучить модель, способную различать эти два класса.

## Описание признаков

В данных встречаются признаки, описывающие:

- **cap-shape** — форма шляпки  
- **cap-surface** — поверхность шляпки  
- **cap-color** — цвет шляпки  
- **bruises** — наличие пятен/повреждений  
- **odor** — запах гриба  
- **gill-attachment** — прикрепление пластинок  
- **gill-spacing** — расстояние между пластинками  
- **gill-size** — размер пластинок  
- **gill-color** — цвет пластинок  
- **stalk-shape** — форма ножки  
- **stalk-root** — тип корня ножки  
- **stalk-surface-above-ring** — поверхность ножки выше кольца  
- **stalk-surface-below-ring** — поверхность ножки ниже кольца  
- **stalk-color-above-ring** — цвет ножки выше кольца  
- **stalk-color-below-ring** — цвет ножки ниже кольца  
- **veil-type** — тип покрывала  
- **veil-color** — цвет покрывала  
- **ring-number** — количество колец  
- **ring-type** — тип кольца  
- **spore-print-color** — цвет спорового отпечатка  
- **population** — плотность популяции  
- **habitat** — среда произрастания  
- **is_smelly** — бинарный индикатор запаха (построен по данным)

Все признаки категориальные, включая добавленный бинарный признак.

## Формат данных

### `train.csv`
Содержит:
- `id`
- все признаки, перечисленные выше  
- `is_poisonous` — целевая переменная

### `test.csv`
Содержит:
- `id`
- те же признаки, кроме `is_poisonous`

### `sample_submission.csv`
Шаблон:
- `id`
- `is_poisonous` (заполнить предсказаниями)

### `answer.csv`
Файл с правильными ответами для тестовой части.

## Цель

Используя признаки, изучить закономерности, которые позволяют отличать ядовитые грибы от съедобных, и построить модель бинарной классификации.
