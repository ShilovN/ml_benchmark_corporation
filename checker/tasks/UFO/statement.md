## Задача: Прогнозирование показателя `ufo_mystery_score` по координатам

Дан набор наблюдений о появлениях НЛО (`scrubbed.csv`).  
Для каждого наблюдения указаны координаты: `latitude`, `longitude`.

Требуется предсказать показатель **`ufo_mystery_score`** — синтетическую метрику, отражающую "интенсивность аномальности" наблюдения (условно моделирует близость к гипотетическому центру активности НЛО).

### Формат данных

#### `train.csv`
- `id`
- `latitude`
- `longitude`
- `ufo_mystery_score` — целевая переменная

#### `test.csv`
- `id`
- `latitude`
- `longitude`

#### `sample_submission.csv`
- `id`
- `ufo_mystery_score` (предсказания модели)

#### `answer.csv`
Содержит правильные значения таргета для тестовой части.

### Цель

Построить модель, способную максимально точно предсказывать `ufo_mystery_score` по географическим координатам объекта.
