# Задача: прогнозирование стоимости жилья

Вам предстоит решить задачу регрессии: по характеристикам объявления о продаже недвижимости необходимо предсказать цену объекта.

Данные содержат дату публикации, параметры квартиры, географические координаты и идентификаторы локации. Целевая переменная:

**`price`** — стоимость объекта недвижимости.

## Формат данных

### `train.csv`
Содержит:
- `id`
- признаки объекта недвижимости
- `price` — целевая переменная

### `test.csv`
Содержит:
- `id`
- те же признаки, кроме `price`

### `answers.csv`
Содержит правильные значения `price` для тестовой части.

## Описание признаков

- `date` — дата объявления
- `level` — этаж квартиры
- `levels` — количество этажей в доме
- `rooms` — количество комнат
- `area` — общая площадь
- `kitchen_area` — площадь кухни
- `geo_lat` — широта
- `geo_lon` — долгота
- `building_type` — тип здания
- `object_type` — тип объекта
- `postal_code` — почтовый индекс
- `street_id` — идентификатор улицы
- `id_region` — идентификатор региона
- `house_id` — идентификатор дома

## Цель

Построить модель, которая минимизирует среднюю абсолютную ошибку предсказания `price`.
